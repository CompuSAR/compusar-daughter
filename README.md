# compusar-daughter
The daughterboard for the [CompuSAR](https://github.com/compusar/compusar) project.

Currently CompuSAR is based on the [Alinx AX7035B board](https://www.en.alinx.com/Product/FPGA-Development-Boards/Artix-7/AX7035B.html). This board has _almost_ everything we
need, but those things we don't have are added in a daughterboard, this project.
